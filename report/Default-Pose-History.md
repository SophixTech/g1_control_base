## 1024-uppick-pose

用户提供的新位姿（保留原始精度）：

```json
    -0.20881313,
    0.43633231

  "waist_user_values": [
    0.53857462,
    0.50677994
  ]
}
```

双臂、头部、腰部 Default 已更新到全部 7 份 G1 YAML 和 Python 配置生成器。

腰部数据单位核对：

- 当前 `raw_joints.h5` 记录的是旧位姿，`state/waist/position` 首帧为 `[0.30148823, 0.44655045]`，头部也与旧位姿相符。
- 旧 YAML 腰部指令为 `[0.30148823, 44.655044556]`，第二项等于原数据乘 100（打印精度略有差异）。
- SDK `robot.py::move_waist` 将第一项从 rad 转为度，第二项直接按 cm 发送。
- 据此沿用同一数据约定：用户新腰部值第一项为 rad，第二项为 m；`0.50677994 m × 100 = 50.677994 cm`。新值不来自当前旧 HDF5，来自用户提供的数据。
- 用户原文中第二项的 `rad` / `29.0364°` 标注不适用于升降高度。

实际写入的腰部 Default：

```yaml
# [俯仰角 rad, 升降高度 cm]
Default: [0.53857462, 50.677994]
```

相对 1019-sidepick-pose 的旧升降高度 44.655044556 cm，增加约 6.022949444 cm。

未提供新的夹爪值，因此保留夹爪默认值。Custom、其他机器人配置保持原样。
