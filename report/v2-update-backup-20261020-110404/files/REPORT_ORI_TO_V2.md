## M03 准备官方训练环境与模型资源

**状态：待实施。**

**主要文件：**使用 `tools/create_train_env.sh`；填写 `configs/vla/real_robot/package_a2d.yaml` 中的资源路径。

**要做什么：**

深度监督的过程是：已有 RGB → MoGe 估计深度 → LingBot-Depth 生成深度特征 → 用这些特征监督 VLA。视频监督由 DINO-Video 从当前和未来 RGB 生成。因此现有数据没有真实深度图也可以训练。

**完成标准：**模型资源在训练服务器上可加载，所有路径指向本地文件。官方启动脚本默认离线，资源需要提前准备。
